---
title: "Quick start: from install to playing guitar in minutes"
description: "Install Neural Amp Modeler Plugin, load a .nam model file and an optional IR, then play guitar through a neural amp capture in your DAW in minutes."
---

This guide gets you from a fresh install to playing guitar through a neural amp model as quickly as possible. You need a DAW with VST3 or AudioUnit support (or the standalone app), a `.nam` model file, and optionally a cabinet IR in `.wav` format.

<Steps>
  <Step title="Install the plugin">
    If you haven't installed the plugin yet, download the pre-built installer from the [GitHub Releases page](https://github.com/sdatkinson/NeuralAmpModelerPlugin/releases) and run it. After installation, rescan plugins in your DAW.

    See the [installation guide](/installation) for platform-specific instructions and file locations.
  </Step>
  <Step title="Get a NAM model file">
    NAM model files use the `.nam` extension. The community shares a large collection of free captures at [neuralampmodeler.com](https://www.neuralampmodeler.com/users#comp-marb84o5). Download one or more `.nam` files and save them to a folder you'll remember.

    <Tip>
      Organize your models by keeping all `.nam` files in a single folder. The plugin's left and right arrow buttons let you cycle through every model in the same directory without opening the file browser each time.
    </Tip>
  </Step>
  <Step title="Load the model in the plugin">
    Open the plugin in your DAW (or launch the standalone app) and locate the model browser at the top of the interface.

    1. Click the **folder icon** next to the model display to open the file browser.
    2. Navigate to the folder where you saved your `.nam` files.
    3. Select a `.nam` file and confirm. The model name appears in the display when it loads successfully.

    Once loaded, audio processed by the plugin passes through the neural network amp model in real time.
  </Step>
  <Step title="(Optional) Load a cabinet IR">
    A cabinet IR adds speaker and microphone coloration after the amp model for a more complete sound. NAM models often capture just the amp head, so adding an IR is recommended unless the model already includes cabinet simulation.

    1. Click the **folder icon** next to the IR display (below the model display).
    2. Select a `.wav` IR file.
    3. The IR toggle activates automatically. You can bypass it at any time using the IR toggle switch.

    <Note>
      If you don't have an IR yet, the plugin works fine without one. You can add an IR later without changing anything else in your signal chain.
    </Note>
  </Step>
  <Step title="Play guitar through it">
    Route your guitar input to the plugin's audio channel in your DAW and play. The plugin processes audio in mono internally, then delivers the output according to your DAW's channel routing.

    <Tip>
      Fine-tune your tone using the **Bass**, **Mid**, and **Treble** knobs in the EQ section. Use the **Noise Gate** to cut hum between notes — lower the threshold if the gate is cutting off the tail of your notes, or raise it if background noise is still audible.
    </Tip>
  </Step>
</Steps>
